# Open SWE — 开源异步编码 Agent 框架
- 来源: https://github.com/langchain-ai/open-swe
- 日期: 2026-03-21
- 标签: coding-agent, async, langchain, langgraph, multi-agent, orchestration
- 摘要: LangChain 开源的异步编码 Agent 框架，对标 Stripe Minions / Ramp Inspect / Coinbase Cloudbot 的内部编码 Agent 架构。

## 要点

### 是什么
企业级内部编码 Agent 的开源实现。基于 LangGraph + Deep Agents 框架，提供云沙盒隔离、多触发源（Slack/Linear/GitHub）、子 Agent 编排、自动 PR 创建的完整工作流。

### 核心架构决策

1. **组合式而非 Fork**
   - 基于 Deep Agents 框架组合构建（类似 Ramp 基于 OpenCode）
   - 好处：可跟随上游升级，同时自定义编排/工具/中间件

2. **云沙盒隔离**
   - 每个任务运行在独立的远程 Linux 沙盒中
   - 支持多个沙盒提供商：Modal、Daytona、Runloop、LangSmith
   - 爆炸半径完全隔离，无需确认提示

3. **中间件机制（关键设计）**
   - `check_message_queue_before_model`：运行中可接收后续消息（Slack/Linear 评论），在下一次模型调用前注入
   - `open_pr_if_needed`：安全网，Agent 没开 PR 时中间件自动补上
   - `ToolErrorMiddleware`：优雅处理工具错误
   - 中间件是确定性的，确保关键步骤不依赖 LLM 行为

4. **多触发源**
   - Slack：在任意 thread 中 @ bot，支持 `repo:owner/name` 语法
   - Linear：在 issue 上评论 `@openswe`
   - GitHub：在 Agent 创建的 PR 上评论，处理 review feedback
   - 每个触发创建确定性 thread ID，后续消息路由到同一运行中的 Agent

5. **子 Agent 支持**
   - 主 Agent 可 spawn 子 Agent 处理并行子任务
   - 每个子 Agent 有独立的中间件栈、todo list、文件操作

### 与业界对比

| 维度 | Open SWE | Stripe Minions | Ramp Inspect | Coinbase Cloudbot |
|------|----------|----------------|--------------|-------------------|
| 基座 | Deep Agents/LangGraph | Fork Goose | 基于 OpenCode | 从零构建 |
| 沙盒 | 可插拔(Modal等) | AWS EC2 预热 | Modal 预热 | 自建 |
| 工具 | ~15 精选 | ~500 按 Agent 分配 | OpenCode SDK | MCPs + Skills |
| 编排 | 子Agent+中间件 | Blueprints | Sessions+子Session | 三种模式 |
| 验证 | Prompt驱动+PR安全网 | 3层(本地+CI+1次重试) | 视觉DOM验证 | Agent委员会+自动合并 |

## 对我们的价值

### 中间件机制（最有价值）
我们的 8 bot 编码流程目前是"派任务→等结果"的同步模式。Open SWE 的中间件设计提供了三个可借鉴的模式：
1. **消息队列注入**：任务运行中可以追加指令，不需要等完再重新派
2. **安全网中间件**：关键步骤（如提交代码、开 PR）由确定性逻辑保底，不完全依赖 LLM
3. **错误优雅处理**：工具失败不直接崩溃，有统一的错误处理层

### 沙盒隔离思路
我们目前 bot 共享同一台机器，没有任务级隔离。Open SWE 的"每任务一沙盒"思路值得在 Phase 5（多 Agent 编排模板）中考虑。

### 确定性 Thread ID
Open SWE 用确定性 thread ID 保证同一 issue 的后续消息路由到同一 Agent。我们的 Discord thread 机制类似，但可以更系统化。

### 局限
- 依赖 LangGraph 生态，不能直接用到我们的 OpenClaw 架构
- 沙盒提供商都是云服务，我们是本地部署
- 思路可借鉴，代码不可直接复用
