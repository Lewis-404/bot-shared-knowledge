## 2026-05-13 追加：招聘信号 & 开发工具

### 招聘信号

- **Andrew Ng/宝玉**：美国失业率4.3%，软件工程师招聘依旧强劲。AI不会造成失业末日而会带来就业狂欢，AI工程师岗位将大量出现在非传统科技公司。`[来源: Andrew Ng/宝玉推文, AI情报局, 2026-05-13]`
- **Augment Code**：218位工程负责人调查——48%代码由AI生成，63%工程师表达技能焦虑，大团队(201-1000人)飙至89%。`[来源: Augment Code调查, AI情报局, 2026-05-13]`

**可落地**：
- 面试话术中引用Andrew Ng数据回应"AI会不会替代程序员"问题
- 扩大投递范围至非纯科技公司的AI应用部门
- 面试中主动聊"AI辅助下工程师的核心价值"，用"理解代码库全局架构+AI生成代码审查"作为差异化定位

### 开发工具

- **op7418**：Codex PPT Skill配图技巧——搜索参考图→基于参考图生成，解决生僻题材事实错误问题（本质是RAG for图像生成）。`[来源: op7418推文, AI情报局, 2026-05-13]`
- **geekbb**：Vercel MDXG让Markdown自带导航、搜索、代码高亮，不改原文件即可变成多页面文档站。`[来源: geekbb推文, AI情报局, 2026-05-13]`

**可落地**：
- Agent图像/文档生成流水线加入搜索→垫图→生成三段式管线
- Agent知识库Markdown考虑MDXG增强可检索性，让MCP工具直接消费结构化文档导航

## 2026-05-14 追加：开发工具、招聘信号 & 模型能力

### 开发工具

- **Anthropic/Claude Code额度提升**：每周额度提50%至7月13日，叠加5小时窗口翻倍，短期缓解Pro用户"用着用着就停"的体验差距。`[来源: AI情报局, 2026-05-14]`
- **vista8/宝玉 wx-cli**：解密本地微信DB + Claude Code推理实现「本地数据+云端推理」混合Agent模式，可复用到邮件/Slack/飞书等有本地数据但无API的场景。Skill+CLI解耦设计值得参考。`[来源: AI情报局, vista8/宝玉推文, 2026-05-14]`
- **宝玉 Cursor Design Mode**：中文提示词生成英文设计文档，语言传递链路被中间层英文system prompt截断。Agent生成类工具需在system prompt层显式传递用户语言偏好，做语言一致性检查。`[来源: AI情报局, 宝玉推文, 2026-05-14]`

**可落地**：
- 7月13日前可加大Claude Code使用密度，关注是否转为永久策略以决定长期工具选型
- 混合Agent模式（本地数据+云端推理）可复用到本地文件分析/日志分析场景
- Agent生成类工具加入语言偏好显式传递，避免system prompt语言截断

### 招聘信号

- **李想/oran_ge**：AI一人公司多数未建立真实生产环境，AI是放大器非替代器，专业的人用AI进入另一高度。`[来源: AI情报局, oran_ge推文, 2026-05-14]`
- **Andrew Ng (via FinanceYF5)**：AI公司定价锚点从SaaS($100-1000/用户/年)转向人力成本($10K+/替代员工)，AI岗位未消失但技能栈重新洗牌。`[来源: AI情报局, Andrew Ng/FinanceYF5, 2026-05-14]`

**可落地**：
- 面试时区分「会用AI」和「专业能力+AI放大」，准备生产环境Agent案例而非demo演示
- 简历突出Agent编排+Context Engineering+多模型路由等新技能栈而非传统CRUD
- Andrew Ng定价锚点分析可用于薪资谈判：你的产出估值对标替代员工成本而非SaaS订阅

## 2026-05-17 追加：记忆系统

### 记忆系统

- **GaryMarcus/Hao Peng**：LLM Agent consolidated memory（压缩提炼后的记忆）可能比无记忆更差，episodic memory 保留原始片段更可靠。`[来源: AI情报局, GaryMarcus/Hao Peng 推文, 2026-05-17]`
- **aiDotEngineer**：Mnemon 开源 Agent 持久记忆系统，支持跨会话状态保持/演化循环/编排/运行时连续性，新加坡数字部长已在个人 AI 栈中试用。`[来源: AI情报局, aiDotEngineer 推文, 2026-05-17]`

**可落地**：
- Agent 记忆层优先存储原始交互片段 + 按需向量检索，而非依赖 LLM 压缩提炼
- Hermes 多 Agent 系统可参考 Mnemon 架构，将 bge-m3 向量检索 + bot-shared-knowledge 整合为可插拔 persistent cognition 层
